# 🤖 Бот для подготовки к ОГЭ по обществознанию

Бот для подготовки к ОГЭ по обществознанию 2026 с теорией и практикой.

## Особенности
- 49 заданий как в реальном ОГЭ
- Полная теория по 6 темам
- Статистика прогресса
- Работает 24/7 на Koyeb

## Как запустить
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` с токеном бота
3. Запустите: `python bot.py`

## Развертывание на Koyeb
1. Залить этот код в GitHub
2. Создать приложение в Koyeb
3. Указать BOT_TOKEN в настройках
4. Запустить!
